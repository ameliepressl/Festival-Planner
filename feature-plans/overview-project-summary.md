# Finances and urgent tasks on Overview

## Why

Show the festival's projected finances and upcoming work as soon as the planner opens.

## What

- Show projected revenue, costs, and profit or loss from the same calculation used in Finances.
- Show up to three overdue or upcoming subtasks from Project tasks, using its existing seven-day window and completion status.
- Link to Finances and the matching task card.
- Bring the current Project tasks, Gantt, map, vendors and Finances into the homepage branch and preserve the homepage and lineup workflows.

## Out of scope

Account creation, shared data and real-time financial transactions.

## Done when

Overview and Finances agree after changes to finance inputs or the festival plan. Completed subtasks are removed from Overview, and each task link opens the correct card. Existing planner tests pass and all sections work through normal navigation.
