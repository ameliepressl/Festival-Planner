# Upcoming milestones on Overview

## Why

Make the next planned finishes visible without opening the whole Gantt chart.

## What

- Show up to three upcoming task-group finishes from the committed Gantt schedule.
- Use the latest scheduled subtask end date as the task group's planned finish.
- Open and focus the selected task group in the Gantt chart using its stable ID.
- Refresh after saved Gantt changes and festival date changes.

## Out of scope

Task completion and overdue tracking. The original Task Board branch is kept intact.

## Done when

The default template and saved schedules both appear. Saving a date updates the list, cancelling leaves it intact, and reordering keeps the links working.
